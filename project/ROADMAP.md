# RaceSplit Roadmap

## Now — MVP polish

### Branding
- Replace remaining DEKA MILE branding with RaceSplit.
- Update browser title, headings and export filenames.
- Add simple RaceSplit identity/logo treatment.
- Confirm racesplit.app HTTPS is fully active.

### Live timing
- Add target time per split.
- Show live ahead/behind value for the current split.
- Show live ahead/behind value for the overall event.
- Make correction controls very fast for early/late taps.
- Review whether transition timing should have a dedicated visual state.

### Event templates
- Improve **Create Event → Blank / From Template** flow.
- Make **Save As** obvious.
- Add rename, duplicate and delete for custom templates.
- Add event description/notes.
- Add more common activities to the activity library.

## Next — training and analysis

### Results
- Compare multiple attempts of the same event.
- Highlight biggest gains/losses by split.
- Separate totals for runs, stations and transitions.
- Add personal best markers.
- Add shareable result summary.

### Targets
- Save target profiles against an event template.
- Allow targets to be created from a previous race.
- Support overall target time with auto-distributed split targets.

### PWA / device use
- Installable web app.
- Offline support.
- Prevent accidental screen sleep during timing where supported.
- Better full-screen race mode.
- Backup/export all local RaceSplit data.

## Later — expansion

- HYROX-style custom templates without using protected branding unless appropriate.
- Community/shared templates.
- Cloud account and sync.
- Multiple athletes / coach mode.
- Event organiser mode.
- Live spectator timing.
- QR/share links for templates.
- Import results from CSV.
- Analytics dashboard.
- Wearable/watch companion exploration.

## Parking lot

- Audio/haptic split confirmation.
- Voice-triggered split capture.
- Automatic station recognition.
- Team/relay events.
- Public template marketplace.
