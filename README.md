# RaceSplit

RaceSplit is a mobile-first multi-event split timer for DEKA-style and custom fitness events.

**Live app:** https://racesplit.app

## Workflow

1. Log the idea, bug or feature as an Issue.
2. Define the problem and acceptance criteria.
3. Agree the solution.
4. Build and test.
5. Commit/merge to `main`.
6. GitHub Pages deploys to production.
7. Verify `racesplit.app`.
8. Update release notes and close the issue.

The goal is to keep product thinking, implementation and deployment connected in one place.
